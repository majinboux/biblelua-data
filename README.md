# Bible & Theological Content CDN

This repository contains biblical and theological data for use in the Sanctum of Spiritborn game.

## Contents

- **Bible Versions**: 80 complete translations (214.29 MB)
- **Commentaries**: 73 books with verse-by-verse commentary (241.33 MB)
- **Church Fathers**: 47 patristic authors (171.97 MB)
- **Dictionaries**: 25 biblical dictionaries (89.52 MB)
- **Cross References**: 66 books with cross-references (1.90 MB)

**Total Size**: 719.00 MB

## Usage

All content is accessed via raw GitHub URLs:

```
https://raw.githubusercontent.com/SanctumOfSpiritborn/biblelua-data/main/bible/KJV.json
https://raw.githubusercontent.com/SanctumOfSpiritborn/biblelua-data/main/commentaries/Genesis.json
https://raw.githubusercontent.com/SanctumOfSpiritborn/biblelua-data/main/church_fathers/Augustine.json
```

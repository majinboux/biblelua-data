# Provenance note \u2014 `bible/Aleppo.json`

Despite its file name, this file is **not** a transcription of the Aleppo
Codex's Genesis. The Aleppo Codex's Torah does not survive: the codex is
missing all of the Pentateuch up to Deuteronomy 28:17, and no Genesis leaf
or fragment of it is known to survive (the only recovered Torah material
since 1947 is a Chronicles leaf and an Exodus 8 fragment).

Checked 2026-10-12 (programme's oldest-witnesses survey): this file is an
unpointed consonantal text of all 39 books. Its Genesis 1\u20132 is
consonantally identical to WLC once punctuation artifacts (maqqef, sof
pasuq, stray marks) are normalized \u2014 i.e. a modern completion in the
ben Asher tradition, not a transcription of surviving codex pages.

Grades: as a Genesis *witness*: FENCED. As a consonantal MT text: FITTED.
